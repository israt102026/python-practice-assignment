# Python Practice Assignment

This repository contains two beginner Python programs.

## Files

- `personal_calculator.py` - Asks for name, age and two numbers, then shows the sum, difference, product and quotient using f-strings.
- `grade_calculator.py` - Takes a student's name and marks for three subjects, calculates the average, and prints the final grade. Marks outside 0-100 are reported as invalid.

## Grading Scale

| Average Marks | Grade |
|---------------|-------|
| 80-100        | A+    |
| 70-79         | A     |
| 60-69         | A-    |
| 50-59         | B     |
| 40-49         | C     |
| Below 40      | F     |

## How to Run

```
python personal_calculator.py
python grade_calculator.py
```
